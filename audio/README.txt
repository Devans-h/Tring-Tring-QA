Proof files for the page (call recordings as .wav, plus one screenshot .png).

Naming: <sr>-<short-name>.wav for Agent Calling problems, t<sr>-... for Telenow problems.
Reference them in ../data.js, e.g.   { file: "audio/06-bg-noise.wav", name: "Background noise" }

Or, while serve.py is running, use "+ Attach recording" on the page; the file is
copied here automatically.
